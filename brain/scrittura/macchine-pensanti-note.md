# Macchine Pensanti — le Note di Substack

Le **Note** sono un genere diverso dalla newsletter: post brevi, reattivi, dialogici,
agganciati alla cronaca; servono a rilanciare e commentare interventi altrui e a
tenere viva la comunità. La newsletter è lo strato-saggio; le Note lo strato-conversazione.

## Limite tecnico (2026-08-31)

Il feed pubblico delle Note (anche in incognito) si vede tutto **solo scrollando**:
è il JavaScript di Substack che, a ogni scroll, fa una nuova chiamata paginata. Il mio
strumento fa **una sola richiesta GET, senza eseguire JavaScript e senza scroll**:
ottengo solo il primo blocco (ultime ~10). I tentativi di paginare a mano l'API
(`cursor=`, `before=`, `offset=`) danno errore 400 o vengono ignorati.
**Per l'archivio completo serve un export o un copia-incolla dalla pagina scrollata.**
